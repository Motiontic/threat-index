# nvd pattern fixtures

Hand-written for the `since` tests, 23 Nov 2026. Shape follows the CVE API 2.0
(https://nvd.nist.gov/developers/vulnerabilities): `totalResults`, `startIndex`, `vulnerabilities[].cve`.
NVD data is public domain (US government); the text here is invented.
`page-0` and `page-1` are two pages of a 3-result window.
