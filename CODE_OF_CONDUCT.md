# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Disagree about ideas, not people.
- No harassment, personal attacks, discriminatory language or unwelcome attention.
- Assume good intent, and give and take constructive feedback gracefully.
- Respect people's privacy. Don't publish others' private information.

**Reporting:** a dedicated conduct email address is coming. Until then, open an issue that only asks a maintainer to contact you privately, and put no details in it. Reports are handled privately and promptly. Maintainers may remove comments, commits or contributions that break this code, and may ban contributors who break it repeatedly or seriously.

This code applies in all project spaces (issues, pull requests, discussions) and when someone represents the project in public.
